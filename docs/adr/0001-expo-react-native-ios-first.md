# Expo React Native for an iOS-first app

The first product target is iOS, implemented with Expo and React Native so that the application, domain model, and financial rules remain readable and debuggable in TypeScript. Small native modules are acceptable at Apple-specific boundaries such as CloudKit, using Expo development builds and local Expo Modules; macOS remains a preferred future target but is deferred and does not constrain the initial stack.
